SSH Honeypot GitHub Repo

  • Architected an interactive SSH honeypot in Python using paramiko and low-level socket wrappers to simulate a vulnerable Linux server and capture automated brute-force attacks.
  • Engineered custom SSH protocol logic by subclassing paramiko.ServerInterface to bypass standard authentication, emulate pseudo-terminals (PTY), and capture raw keystrokes.
